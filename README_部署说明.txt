《特别出演》完整可编辑网站

上传整个 ZIP 到现有 Cloudflare Pages 项目的生产环境部署。
/ 是可读 3D 书； /studio.html 是完整编辑器。
首次打开编辑器时，将部署包内的排版、手账素材、字体、音视频导入当前浏览器 IndexedDB；已有本地草稿不会被覆盖。

警告：本 ZIP 及其线上站点包含完整私人素材、字体和媒体文件。任何知道网址的人都有可能读取或下载这些资源。建议对编辑器及整个私有工程启用 Cloudflare Access，公开分享请使用只读版。

IMPORTANT: Cloudflare Pages 是静态托管，手机或电脑网页上的继续编辑只会保存在当前设备。再次更新线上版本，需从有完整素材的编辑器重新导出此 ZIP 并在 Cloudflare 重新部署。

Cloudflare Pages 控制台单文件上限 25MiB，拖放部署最多 1000 文件；超过应使用 Wrangler（最多 20,000 文件，仍受单文件限制）。
